# Travel Agency AI Booking Agent

An end-to-end AI-powered travel booking automation system built with n8n, Google Gemini, Stripe, and Gmail. It helps customers explore tours, check availability, create bookings, and complete payments through an automated workflow.

## Workflows

### 1. Travel Agency AI Booking Agent

A conversational AI agent that helps customers explore available tours, check pricing and availability, create bookings, generate Stripe checkout links, and receive payment emails through Gmail.

📁 [View Travel Agency AI Booking Agent](./01-travel-agency-ai-booking-agent/)

### 2. Travel Agency Payment Confirmation

A Stripe webhook workflow that processes successful payments, updates booking status in the Data Table, and sends booking confirmation emails through Gmail.

📁 [View Payment Confirmation Workflow](./02-travel-agency-payment-confirmation/)
